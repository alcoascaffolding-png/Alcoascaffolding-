## Monitor weekly (first month)

- Coverage / Page indexing: soft 404s, redirects, duplicate without user-selected canonical
- Performance: CTR on impressions >1k — rewrite titles/meta if CTR <1%
- Top queries: ensure each maps to one primary URL

## Technical checks

- View source on key URLs: unique `<title>`, meta description, canonical present without JS.
- Rich Results Test on homepage (LocalBusiness) and `/faq` (FAQPage).
- Mobile PageSpeed — target 80+ after image work.
